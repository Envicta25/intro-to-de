# 🌀 Ouro — Looped Language Model for Latent Reasoning

[Ссылка на оригинальную статью](https://arxiv.org/abs/2510.25741)


**Ouro** (назван в честь Уробороса — змеи, кусающей свой хвост) — это реализация **циклической языковой модели** (LoopLM), которая встраивает итеративное рассуждение **в латентное пространство**, а не в явно генерируемые токены (как Chain-of-Thought). Модель предобучена на 7.7T токенов и использует энтропийную регуляризацию для динамического выделения «глубины» вычислений.

> 📌 **Ключевая идея:** модель может «думать» внутри своих скрытых состояний, повторно применяя один и тот же слой несколько шагов, прежде чем сгенерировать следующий токен.



## ✨ Особенности

- **Латентное рассуждение** — итеративная обработка в скрытом пространстве без генерации промежуточных токенов
- **Петлевая архитектура** — повторное использование одного слоя с адаптивным числом итераций
- **Масштабирование рассуждения** — увеличение вычислительных затрат на этапе вывода без роста числа параметров
- **Энтропийная регуляризация** — обучение модели определять, когда остановить внутренние итерации
- **Совместимость** — модель работает как обычная авторегрессионная LM, но с опциональным параметром `num_loops`

## 🚀 Быстрый старт

Создание модели и генерация с динамической глубиной вычислений (*learned depth*).

```python
# Конфигурация (пример для версии 1.4B)
config = OuroConfig(
    vocab_size=50272,
    hidden_size=2048,
    num_loop_layers=8,       # число слоёв, участвующих в циклических вычислениях
    max_loop_iters=12,       # максимальное количество латентных итераций
    entropy_reg_weight=0.01  # коэффициент энтропийной регуляризации
)

model = OuroModel(config)

# Генерация с адаптивным количеством циклов
output = model.generate(
    input_ids,
    max_new_tokens=100,
    adaptive_loops=True,     # модель самостоятельно определяет глубину вычислений
    temperature=0.7,
)
```
